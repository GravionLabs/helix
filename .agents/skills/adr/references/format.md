# ADR format (elysion)

File `docs/adr/NNNN-<slug>`, four digits, lowercase slug. Example: ADR 0029 "dot voting on the server" of elysion.

```markdown
# ADR 0029: Dot voting on the server

- Status: Proposed
- Date: 2026-10-31
- Issues: #12
- Supersedes: [ADR 0020](0020-facilitation-state.md)
- Builds on: [ADR 0006](0006-shared-local-infrastructure.md)

## Context

## Decision

## Consequences

## Alternatives
```

Status values: `Proposed` (default), `Accepted` (owner only), `Superseded by ADR nnnn`, `Superseded in part by ADR nnnn (<what>)`. Issues, Supersedes and Builds on are optional.
