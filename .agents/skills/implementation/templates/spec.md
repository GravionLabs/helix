# <Service> spec (<stack>)

## Owner

Team or person who owns the service and answers questions about it.

## Responsibilities

What the service does and what it deliberately does not do.

## API

Endpoints, routes or protocol: path or message, input, output, error cases.

## Authentication

How callers prove who they are and what each role may do.

## Logging

What is logged, at which level, and which fields never appear.

## Configuration

Settings, environment variables and feature flags with defaults.

## Open questions

Decisions still open about the service; remove an entry when it is decided.
